# 昨日登录结果与次日状态

同一个模拟人物在第 4 天独立尝试登录。从同一份操作前状态分别给出“成功”和“尝试后失败”两个结果，计算各自的任务经历、心理和效能，再比较第 5 天 09:00 面对同一新登录机会时的行为。

## 实现与验收

- [x] 在 `hourly_feedback_state.py` 复用生产模型更新状态，保存操作前、操作后和第 5 天观察时刻的证据。第 4 天的结果是实验干预。
- [x] 用同一分支生成 Plan、任务评价和策略输入。核对同场景的人物、需求、机会、时间、配对种子与抽样值，只容许该分支能推出的状态和经历有变化。
- [x] 实验入口增加 `--feedback-mode updated`，归档模式、分支输入和来源。原 `frozen` 条件可复核一次成败记忆的直接作用。
- [x] 使用真实参考历史与合成历史离线准备，以本地 HTTP 替身验证在线执行路径并完成回归。

沿用 24 点配对、模型和策略权重。上层 LLM 独立选定现在办理、延期或其他合法行动；低层使用原来的规则和模型融合。新试验测量经历连同其后果的合并作用。今天的需求和新机会固定，昨天未完成任务的持续跟踪以及真实人群的验证属于不同研究问题。

更新版中的两组使用同一个第 4 天任务 ID 和事件 ID，保留规则生成的操作后变化。旧版使用手工构造的短事件记录。跨版本比较同时涉及事件内容的详略和人物状态；单看跨版本的差值无法估计无助感、信任或效能中某一项的独立作用。
