# TalkingData 老年用户数据集可做事项

## 结论

这个数据集可以帮助我们把 digital friction agent simulation 从手写任务频率，推进到真实老年/中老年手机使用轨迹校准。

但它不能直接证明 helplessness 或 controllability。它记录的是手机使用痕迹，不是任务成功/失败、求助、放弃原因或心理状态。

最稳的定位是：

```text
TalkingData provides empirical mobile-use traces used to calibrate task exposure,
activity rhythms, agent heterogeneity, and validation targets for the simulation.
```

不要写成：

```text
TalkingData directly measures digital helplessness.
TalkingData directly labels success/failure/help-seeking/controllability.
```

## 可做事项

### 1. 校准任务暴露频率

可以从 `category` 和 `timestamp` 中估计老年用户真实会遇到哪些数字场景：

```text
finance / payment / risk
shopping / service
social / communication
navigation / travel / location
information / search / judgment
health / medical
entertainment
```

这些可以映射到当前 simulation 的 task family：

```text
payment_risk_confirmation
service_application_submission
account_login_verification
navigation_service_location
information_search_judgment
profile_form_upload
```

用途：

```text
让 agent 每天遇到的任务类型更接近真实手机使用轨迹。
让不同 task family 的出现频率由数据驱动，而不是完全手写。
```

### 2. 校准 agent 异质性

每个 `device_id` 可以构建一个真实用户 profile：

```text
年龄
性别
手机品牌
手机型号
日活跃量
活跃时段分布
常用 category 分布
active category 多样性
finance/risk exposure
social/support exposure
navigation/travel exposure
```

这些可以映射到 agent 初始特征：

```text
digital_experience
task familiarity
risk exposure
activity regularity
app diversity
device friction proxy
support/social exposure proxy
```

注意：这些是 proxy，不是直接心理变量。

### 3. 校准时间节律

数据中有真实 `timestamp`，可以估计：

```text
小时级活跃分布
每天活跃量
weekday/weekend 变化
用户级活跃稳定性
category-by-hour 分布
```

用途：

```text
替代当前固定 EVENT_DECISION_INTERVAL_MINUTES=60 的均匀触发假设。
生成更真实的 event schedule。
```

例如当前粗略统计显示，活跃高峰集中在早晨时段：

```text
06:00-10:00 附近更活跃
```

### 4. 做 reference -> validation 外部验证

数据天然切成：

```text
May 1-3: reference
May 4-7: validation
```

推荐使用方式：

```text
用 May 1-3 初始化/校准每个 agent 的行为基线。
让 simulation 生成 May 4-7 行为。
将模拟输出与真实 May 4-7 聚合统计对比。
```

可验证指标：

```text
daily active volume
hourly activity profile
category distribution
active category distribution
finance/payment exposure rate
social/communication exposure rate
navigation/travel exposure rate
user-level activity rank stability
reference-to-validation category persistence
drop-off / retention proxy
```

这可以支持论文中的外部校准和验证：

```text
The simulation is calibrated against observed mobile-use traces and evaluated on
held-out future days at the aggregate and user-profile level.
```

### 5. 构建 retention / drop-off proxy

虽然没有真实 `avoid` 或 `helplessness` 标签，但可以从时间序列中构造 proxy：

```text
某用户在 reference 常用某 category，validation 是否继续活跃
某 category 的 active rows 是否下降
某用户日活跃量是否下降
高风险金融类 category 是否更不稳定
```

这些可以用于：

```text
校准 avoid/drop-off proxy
验证 simulation 是否能产生类似的持续使用/流失模式
```

边界：

```text
只能称为 proxy，不能直接称为 helplessness 或 controllability。
```

## 不能直接做的事项

这个数据集不能直接提供：

```text
任务成功 / 失败
用户是否求助
用户是否主动回避
失败原因
helpfulness / support quality
helplessness
self-efficacy
controllability
attribution
```

因此不能直接用它训练或验证：

```text
helplessness_delta
C_family
C_global
seek_help_then_attempt
failure_after_attempt
failure_even_with_help
avoid_reason
```

这些仍然属于 simulation 内部机制变量。

## 接入 simulation 的推荐方式

### Step 1: 只做 profile，不改 agent

先写 profiling 脚本，生成聚合文件。

目标：

```text
确认 task family mapping 是否合理。
确认 reference/validation 是否稳定。
确认用户异质性是否明显。
```

### Step 2: 用数据校准 task scheduler

将 task 采样从固定手写频率改成：

```text
按 user profile 的 category/task-family 分布采样。
按 hourly activity profile 决定事件触发时间。
```

这一步不改变 psychological update，也不改变 policy logic。

### Step 3: 用数据初始化 agent profile

用真实用户 profile 初始化：

```text
age
gender
device familiarity proxy
finance/risk exposure
social/support exposure
activity regularity
category diversity
```

### Step 4: 用 validation 做外部检验

模拟 May 4-7，比较：

```text
真实 validation task-family distribution
模拟 task-family distribution
真实 active volume
模拟 event volume
真实 category retention proxy
模拟 avoid/drop-off proxy
```

## 论文写法建议

可以说：

```text
We use anonymized mobile-use traces from the TalkingData dataset to calibrate
task exposure, activity rhythms, and user heterogeneity for older mobile users.
```

可以说：

```text
The first three days are used as a reference window and the last four days as a
held-out validation window.
```

可以说：

```text
Because the dataset does not contain explicit success, help-seeking, or
psychological-state labels, it is used for behavioral calibration rather than
direct supervision of helplessness or controllability.
```

不要说：

```text
TalkingData labels digital helplessness.
TalkingData validates our controllability trace directly.
TalkingData records success/failure outcomes.
```

## 当前判断

这个数据集对我们的实验非常有价值，但价值不在于直接替代机制模型。

它的价值是：

```text
提供真实手机使用底座
校准任务暴露和时间节律
构造真实 agent 异质性
提供 reference -> validation 的外部检验目标
```

机制部分仍由我们的 simulation 负责：

```text
action-outcome posterior
controllability trace
helplessness / self-efficacy update
attempt / help / avoid policy
```
